# sglang-neuron (RL post-training fork)

A working fork of [sgl-project/sglang-neuron](https://github.com/sgl-project/sglang-neuron), the SGLang plugin for AWS
Trainium: the rollout server for RL post-training on Trainium2, and the source of upstream pull requests for what holds
up on hardware. The plugin itself: the [upstream README](https://github.com/pengchenglu1997/sglang-neuron/blob/upstream-main/README.md) and [docs/](docs/index.md).

- **For:** a fast rollout server for RL post-training on Trainium2.
- **Headline metric:** output tokens per second at concurrency 32 (prompt 1,024 tokens, 256 output tokens, one chip as TP4).
- **Compared with:** vllm-neuron 0.29.0.1.2.0 measured in the same session, and this fork's own code with its switches off.
- **Tier:** every number is `screen` (at least 2 passes on one server start) or lower; a difference under 10 percent is
  not distinguished at that tier ([rl/METHOD.md](rl/METHOD.md)). Claims and sources: [docs/rl/RESULTS.md](docs/rl/RESULTS.md).

## Switches this fork adds

Read from the code on `main` by `python rl/tools/switches.py` (other branches: `--branch origin/integration`). The
compile-cache stamp fix has no switch. Other kernel switches: [docs/rl/KERNELS.md](docs/rl/KERNELS.md).

<!-- switches:begin generated by rl/tools/switches.py from the code; do not edit -->
| Variable | Default | On by default | Purpose | Branch |
|---|---|---|---|---|
| `RLKIT_SAMPLER_KERNEL` | `0` | no | the shard-local stage of the temperature sampler (sampling.sample_sharded_logits, v0.1.0) as one NKI kernel | `main` |
| `SGLANG_NEURON_LM_HEAD_PRETRANSPOSED` | `0` | no | 1 gives the LM head its own [H, V / tp] weight, the layout its matmul reads, filled from the checkpoint tensor at load | `main` |

## Branches

State (open branches, pull requests, our upstream pull requests, the mirror) is read, not written here: `bash rl/tools/fork_state.sh`

| Branch | What it holds | Who writes to it |
|---|---|---|
| `main` | Upstream plus our changes that ran on Trainium2 hardware, plus the team paths (`rl/`, `docs/rl/`, `.github/`, this page, `AGENTS.md`). Start new work here. | Pull request |
| `integration` | `main`, plus changes that did not run on hardware, plus upstream pull requests we carry | Pull request labelled `cpu-only` |
| `upstream-main` | The upstream `main`, unchanged; moved by hand when upstream moves | Nobody; it is a copy |
| `feat/*`, `fix/*` | One piece of work each; a branch meant for upstream starts from `upstream-main` | Whoever claimed the work |
